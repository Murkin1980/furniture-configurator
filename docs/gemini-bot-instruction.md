# Инструкция для Gemini-бота: генерация ракурсов товара

## Проект
Визуальный конфигуратор мебели. Для каждого товара нужно 8 изображений товара с разных ракурсов для каждой комбинации опций (материал, цвет, ножки, размер).

---

## Входные данные

Пользователь присылает **одно фото товара** (любой ракурс).

## Задача бота

Сгенерировать 8 изображений товара по цоклву (0–7) для каждой комбинации опций, которые указаны в конфиге товара. Изображения должны сохраняться строго по системе именования проекта.

---

## Система именования файлов

```
{angle}-{material}-{color}-{legs}-{size}.webp
```

### Ракурсы (angle 0–7)

| Индекс | Название | Описание |
|--------|----------|----------|
| 0 | Вид спереди | Прямой фронтальный вид |
| 1 | Передний правый угол | 45° справа от фронта |
| 2 | Вид справа | Профиль справа |
| 3 | Задний правый угол | 45° справа сзади |
| 4 | Вид сзади | Прямой задний вид |
| 5 | Задний левый угол | 45° слева сзади |
| 6 | Вид слева | Профиль слева |
| 7 | Передний левый угол | 45° слева от фронта |

### Параметры опций

Бот должен сгенерировать отдельный набор из 8 ракурсов для каждой комбинации опций.

**Пример конфига товара (диван):**

```js
{
  id: 'sofa-classic',
  name: 'Диван классический',
  basePrice: 250000,
  currency: 'KZT',
  options: [
    {
      id: 'material',
      values: [
        { id: 'fabric', imageSuffix: 'fabric' },        // Ткань
        { id: 'eco-leather', imageSuffix: 'ecoleather' }, // Эко-кожа
        { id: 'velvet', imageSuffix: 'velvet' },          // Велюр
      ],
    },
    {
      id: 'color',
      type: 'color',
      values: [
        { id: 'ivory', imageSuffix: 'ivory', hex: '#FFFFF0' },
        { id: 'grey', imageSuffix: 'grey', hex: '#808080' },
        { id: 'blue', imageSuffix: 'blue', hex: '#1E3A5F' },
        { id: 'brown', imageSuffix: 'brown', hex: '#5C3A2E' },
        { id: 'black', imageSuffix: 'black', hex: '#1A1A1A' },
        { id: 'white', imageSuffix: 'white', hex: '#F5F5F5' },
        { id: 'green', imageSuffix: 'green', hex: '#0B6623' },
        { id: 'burgundy', imageSuffix: 'burgundy', hex: '#800020' },
      ],
    },
    {
      id: 'legs',
      values: [
        { id: 'wood', imageSuffix: 'wood' },     // Деревянные
        { id: 'metal', imageSuffix: 'metal' },   // Металлические
        { id: 'none', imageSuffix: 'none' },      // Без ножек (цоколь)
      ],
    },
    {
      id: 'size',
      values: [
        { id: '2seat', imageSuffix: '2seat' },   // Двухместный (140 см)
        { id: '3seat', imageSuffix: '3seat' },   // Трёхместный (200 см)
        { id: 'corner', imageSuffix: 'corner' },  // Угловой
      ],
    },
  ],
}
```

## Технические требования к изображениям

- **Формат:** WebP
- **Размер:** 880 × 660 px (соотношение 4:3)
- **Фон:** прозрачный или однородный светлый (#f8f8f8)
- **Товар:** по центру кадра, заполняет примерно 70-80% высоты
- **Перспектива:** изометрическая или реалистичная 3D-визуализация, единый стиль на все ракурсы
- **Освещение:** равномерное, без резких теней, товар хорошо читается
- **Одна опция меняется за раз** — товар должен отличаться только соответствующим параметром (цветом обивки, типом ножек, размером), геометрия и ракурс идентичны во всех комбинациях

## Формат ответа бота

После генерации бот возвращает JSON-отчёт:

```json
{
  "productId": "sofa-classic",
  "totalImages": 576,
  "combinations": 72,
  "angles": 8,
  "baseImage": "исходное_фото_пользователя.webp",
  "status": "completed",
  "folder": "products/sofa-classic/images/"
}
```

### Подсчёт комбинаций

Для дивана из примера:
- Материал: 3 варианта
- Цвет: зависит от материала (fabric: 3, eco-leather: 3, velvet: 2) = 8
- Ножки: 3 варианта
- Размер: 3 варианта

Всего: 3 × 8 × 3 × 3 = 216 комбинаций × 8 ракурсов = 1728 изображений.

---

## Принцип работы с опциями-зависимостями

Некоторые цвета доступны только для определённых материалов:

| Материал | Доступные цвета |
|----------|----------------|
| fabric (Ткань) | ivory, grey, blue |
| eco-leather (Эко-кожа) | brown, black, white |
| velvet (Велюр) | green, burgundy, blue |

Бот должен генерировать только валидные комбинации.

---

## Пример работы

1. Пользователь загружает фото дивана
2. Бот определяет товар (по умолчанию `sofa-classic`)
3. Бот генерирует 1728 WebP-изображений (216 комбинаций × 8 ракурсов)
4. Файлы сохраняются в `products/sofa-classic/images/`
5. Бот возвращает JSON-отчёт с результатом
