# Система именования WebP-файлов

## Формат имени файла

```
{angle}-{material}-{color}-{legs}-{size}.webp
```

### Компоненты

| Часть | Описание | Пример |
|-------|----------|--------|
| `{angle}` | Номер ракурса (0–7) | `0`, `1`, `2` |
| `{material}` | Материал обивки | `fabric`, `ecoleather`, `velvet` |
| `{color}` | Цвет | `ivory`, `grey`, `blue` |
| `{legs}` | Тип ножек | `wood`, `metal`, `none` |
| `{size}` | Размер | `2seat`, `3seat`, `corner` |

### Примеры

```
0-fabric-ivory-wood-2seat.webp    — Двухместный, ткань айвори, деревянные ножки, вид спереди
3-velvet-burgundy-metal-3seat.webp — Трёхместный, велюр бордовый, металлические ножки, задний правый
5-ecoleather-black-none-corner.webp — Угловой, эко-кожа чёрная, без ножек, задний левый
```

## Ракурсы (0–7)

| Индекс | Название |
|--------|----------|
| 0 | Вид спереди |
| 1 | Передний правый угол |
| 2 | Вид справа |
| 3 | Задний правый угол |
| 4 | Вид сзади |
| 5 | Задний левый угол |
| 6 | Вид слева |
| 7 | Передний левый угол |

## Структура папок

```
products/
  {product-id}/
    images/
      0-fabric-ivory-wood-2seat.webp
      1-fabric-ivory-wood-2seat.webp
      ...
```

## Правила

1. Все имена файлов — в нижнем регистре
2. Разделитель — дефис (`-`)
3. Допустимые символы в частях: `[a-z0-9]`
4. Изображения должны быть в формате WebP (оптимальный размер: 880×660 px)
5. Для каждого товара нужно 8 ракурсов × все комбинации опций
